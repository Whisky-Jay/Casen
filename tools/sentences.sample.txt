# Casen 句子库格式
#
#   - 一行一句中文，空行和 # 开头的行会被忽略
#   - @标签 单独占一行，给它后面的句子打标签，可以中途切换
#   - 同一句重复导入会被跳过，所以反复导入同一个文件是安全的

@日常

我今天特别累，什么都不想干。
这周末你有什么打算吗？
我一般早上六点半起床。
能不能把空调关一下，有点冷。
这家店的东西又贵又难吃。

@时态

我在这家公司工作了五年了。
我昨天没收到你的邮件。
等我到的时候，电影已经开始了。
如果我知道你会来，我就多买点菜了。
我本来打算给你打电话的，结果忘了。

@地道表达

这件事我一时半会儿说不清楚。
他这个人说话不算数。
我们边走边聊吧。
你别往心里去，他不是那个意思。
说起来容易，做起来难。
